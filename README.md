# 光伏电站并网验收与缺陷闭环平台

基于Nuxt3、PrimeVue、Pinia、Nuxt Router、TanStack Query、ofetch、Vite和TypeScript的独立前端工程。Nuxt提供页面路由和服务端构建，业务数据在浏览器本地持久化。

## 功能

- 方阵、逆变器、汇流箱、变压器和并网点的设备树。
- 绝缘、接地、通信、保护、发电性能等验收项和证书附件。
- 建设单位、设备厂家、运维单位多方处理说明。
- 联合复验轮次、整改退回、带条件接受和关闭校验。
- 并网前完整性与证书有效期检查，签署锁定和交付包导出。
- 外部核验回执接入完整性检查：接收即与设备台账对账，核验结论只由回执推导，不再手工勾选。

## 核验回执对账规则

- 回执与台账按证书编号对账；老证书缺回执编号先判“待核”，回执到达并对上台账后补登编号。
- 两个窗口同时提交同一回执编号时先到保留，后到窗口只补新增条目；已登记回执重复接收不重复登记。
- 同一证书编号存在多份回执时以最新版本为准（版本相同取最后接收）；已撤销、已换版或回执版本落后的证书不得通过。
- 传输失败的条目挂在批次 pending 上，重传只补未写入部分，已写入的自动按重复跳过。
- 同一证书编号挂多台设备列为阻断项，可在设备页摘除误挂证书；台账外回执同样阻断签署。
- 回执变化推翻已核验结论时，已签署批次自动失效、电站退回待复核，挂载相关证书的已验收设备改判待核。

端口为`18467`。

```bash
npm install
npm run build
npm run dev
npm run verify   # 纯函数 + store 业务规则断言
```
