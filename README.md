# 光伏电站并网验收与缺陷闭环平台

基于Nuxt3、PrimeVue、Pinia、Nuxt Router、TanStack Query、ofetch、Vite和TypeScript的独立前端工程。Nuxt提供页面路由和服务端构建，业务数据在浏览器本地持久化。

## 功能

- 方阵、逆变器、汇流箱、变压器和并网点的设备树。
- 绝缘、接地、通信、保护、发电性能等验收项和证书附件。
- 建设单位、设备厂家、运维单位多方处理说明。
- 联合复验轮次、整改退回、带条件接受和关闭校验。
- 外部核验回执接收登记：按回执编号/行号幂等，两个窗口同提先到保留、后到只补新增条目；传输失败重试只补未写入部分。
- 回执与证书台账自动对账：同一证书编号以回执最新版本为准；已撤销、换版、版本不符、同一编号挂多台设备、老证书缺回执编号一律改判待核，不得算通过。
- 回执变化导致对账结论改变时，已签署批次自动失效（改判待复核），挂载设备回到待核。
- 并网前完整性与证书有效期检查，签署锁定（含对账结论快照）和交付包导出。

端口为`18467`。

```bash
npm install
npm run build
npm run dev
```
